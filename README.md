# Proyecto GeoVan - Sistema de control de citas 

Este proyecto es mi entregable final, un proyecto que busca solucionar los problemas de muchos estilistas en dar visibilidad a sus negocios, les permitira ofrecer sus servicio de manera mas abierta, permitira a clientes poder encontrar una gran variedad de sitios y escoger segun su necesidad.

## Tecnologías utilizadas
* **Backend:** Java (JDK )
* **Base de Datos:** MySQL 8.0
* **Frontend:** Web (HTML5, CSS3, JavaScript)
* **Gestión de BD:** MySQL Workbench

## Estructura del Proyecto
* `/database`: Scripts de creación de las tablas.
* `/backend-java`: Lógica de servidor y conexión.
* `/frontend-web`: Interfaz de usuario para clientes y estilistas.
* `/docs`: Documentación técnica y diagramas.

## Instalación
1. Clona el repositorio.
2. Ejecutar el archivo `database/tablas_base.sql` en un servidor MySQL.
3. Abrir la carpeta `backend-java` en NetBeans.
4. Configurar credenciales en el archivo de conexión.
